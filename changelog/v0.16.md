# FlagParse.h

- Removed ton of functions that were just aliases to same dynamic
  array functions. (@WolodiaM)
  * `cbuild_arglist_get`.
- Added options for flag parser to allow using it for applications
  with subcommands. To do so, you need to setup global arguments, then
  run parser with `subcommands` set to true. This will stop parsing as
  soon as at first positional argument is encountered. But this argument
  would be stored into as lone element in positional arguments array.
  Then you can add more flags specific to this subcommand and run parser
  again with`keep_argv0` and `reset_pargs` set to true, which will not
  overwrite preserved argv0 value and will reset positional arguments
  array before actually parsing. (@WolodiaM)
  * `cbuild_flag_parse`
  * `cbuild_flag_parse_opt`
  * `cbuild_flag_parse_opts_t`

# Map.h

- Complete rewrite. Now it is open-addressing map with double-hashing
  to resolve collisions. `splitix64` is used to derive step value
  from original hash (as doing second hashing of data is more problematic
  I just derive second hash from first one). This map is based over
  dynamic array and just extends it. It uses tombstones for deletion,
  so repeted deletion now result in degraded performance. Built-in
  support is provided for keys of numerical types (with arbitrary number
  of bytes for such number), c strings, string views and string builders
  (this implies only default hashing and key comparison functions and
  function to initialize such map with valid callbacks). (@WolodiaM)
  * `cbuild_map_init_num`.
  * `cbuild_map_init_cstr`.
  * `cbuild_map_init_sv`.
  * `cbuild_map_init_sb`.
  * `cbuild_map_find`.
  * `cbuild_map_find_idx`.
  * `cbuild_map_append`.
  * `cbuild_map_get`.
  * `cbuild_map_rehash`.
  * `cbuild_map_resize`.
  * `__cbuild_map_num_hash`.
  * `__cbuild_map_cstr_hash`.
  * `__cbuild_map_sv_hash`.
  * `__cbuild_map_sb_hash`.
  * `__cbuild_map_num_keycmp`.
  * `__cbuild_map_cstr_keycmp`.
  * `__cbuild_map_sv_keycmp`.
  * `__cbuild_map_sb_keycmp`.
  * `__cbuild_map_step`.
  * `cbuild_map_hash_djb2`.
  * `cbuild_map_hash_fnv1`.
  * `cbuild_map_hash_fnv1a`.
  * `cbuild_map_hash_sdbm`.
